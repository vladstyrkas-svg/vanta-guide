VANTA GUIDE — CASINO GUIDE PRO

Демонстрационное PWA (4 экрана): Главная, Каталог, Подборки, Избранное.
Все названия платформ, оценки и предложения вымышлены. Приложение не принимает реальные ставки, платежи и регистрации.

БЫСТРЫЙ ПРОСМОТР НА WINDOWS
Откройте index.html. Так работают интерфейс, кнопки, поиск и избранное.

УСТАНОВКА КАК PWA
Для реальной установки разместите всю папку на HTTPS-хостинге, например GitHub Pages.
Откройте HTTPS-ссылку в Chrome на Android. Через меню браузера выберите «Установить приложение» или «Добавить на главный экран».
При открытии локального file:// service worker и установка не работают — это ограничение браузеров, а не ошибка.

Для тестирования на ПК без публикации можно запустить локальный сервер из папки:
python -m http.server 8000
После этого открыть http://localhost:8000

ДЕЙСТВИЯ
- 4 экрана с нижней навигацией
- Поиск и фильтры в каталоге
- Сортировка по рейтингу
- Карточки с подробностями
- Добавление в избранное (localStorage)
- Сравнение двух платформ
- Демо-промокоды с копированием
- Web app manifest, иконки 192/512 и service worker для офлайн-доступа после первого посещения
